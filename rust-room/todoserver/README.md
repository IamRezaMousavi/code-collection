# todo server

A RESTful api server for todo list app implement in Rust

----------------------

## Usage

Install `Rust` and `git` and run this:

```bash
git clone <project-url>
cd <project-dir>
cargo run
```

### for change port

```bash
cargo run -- -p <port_number>
```

### for build

```bash
cargo build --release
```
